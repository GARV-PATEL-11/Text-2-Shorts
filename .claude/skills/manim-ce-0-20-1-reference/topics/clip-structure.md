## Topic: clip structure (project convention — required)
You write ONE file, `clips/clip_NN.py`, containing exactly one function `def clip_NN(self):`.
`scene.py` is generated by `scene_harness.py compose` and binds every clip function to `SceneNN`; never edit it.
- Objects crossing clip boundaries live in `self.reg` under the names of the continuity contract.
  Read only names listed in your ENTRY contract; leave exactly your EXIT contract names in `self.reg`
  and on screen; `self.reg.pop(name)` + FadeOut for anything you remove.
- Do not re-create objects the entry contract says are on screen; do not leave unlisted objects behind
  (FadeOut temporary helpers before the clip ends).
- Each clip becomes its own Manim section: the harness renders your clip alone (earlier clips run with
  `skip_animations`), so the entry state is exactly what the previous clip left — no reconstruction code.
- `self.play(..., run_time=...)` on every call; the timing checker compares the clip span to its narration seconds.
- Imports: only `from manim import *` (+ math, numpy, random). No file, network or process access.
```python
from manim import *


def clip_02(self):
    # entry: reg["eq"] at top_center · exit: reg["eq"] at top_center
    box = SurroundingRectangle(self.reg["eq"], buff=0.15)
    self.play(Create(box), run_time=1)
    self.wait(1)
    self.play(FadeOut(box), run_time=0.5)
```
