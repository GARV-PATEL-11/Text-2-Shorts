## Topic: clip structure (project convention — required)
You write ONE file, `clip_NN.py` (built in the clip's work folder, installed to `clips/`), containing exactly one
function `def clip_NN(self):`.
`scene.py` is generated by `scene_harness.py compose` and binds every clip function to `SceneNN`; never edit it.
- Objects crossing clip boundaries live in `self.reg` under the names of the continuity contract.
- Clips of a scene are built in parallel, each checked on its own. Take every ENTRY object with
  `obj = self.entry("name", lambda: <object as its ENTRY description says>)`: in the composed scene this returns the
  object the previous clip left (make() is not called); when your clip runs alone it builds and shows it.
  `./check static` reports ENTRY_NOT_STANDALONE for an entry object taken any other way.
- Leave exactly your EXIT contract names in `self.reg` and on screen; `self.reg.pop(name)` + FadeOut for anything
  you remove; FadeOut temporary helpers before the clip ends.
- Mark each planned beat with `self.beat(n)` where its animation starts (BEAT_MARKS_MISSING otherwise).
- `self.play(..., run_time=...)` on every call; the timing checker compares the clip span to `CLIP_SECONDS`
  (lead-in + narration + hold, see timing-and-sync).
- Imports: only `from manim import *` (+ math, numpy, random). No file, network or process access.
```python
from manim import *


def clip_02(self):
    # entry: reg["eq"] at top_center ("MathTex a^2+b^2=c^2, WHITE") · exit: reg["eq"] at top_center
    eq = self.entry("eq", lambda: MathTex(r"a^2 + b^2 = c^2").to_edge(UP))
    self.beat(1)
    box = SurroundingRectangle(eq, buff=0.15)
    self.play(Create(box), run_time=1)
    self.wait(1)
    self.play(FadeOut(box), run_time=0.5)
```
